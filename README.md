# Zettel

Enterprise work management with collaborative documents, tables and automation.

**Status: planning.** This repository establishes the product direction and contribution workflow. There is no runnable application or enterprise-ready release yet.

## Direction

Read [product research and roadmap](docs/product-research.md) for capability scope, architecture alternatives, primary sources, and release gates.

## Contribute

Start with an issue that defines a user outcome, acceptance criteria and verification steps. See [CONTRIBUTING.md](CONTRIBUTING.md), [SECURITY.md](SECURITY.md), and [AGENTS.md](AGENTS.md).

## Local validation

Requires Python 3.11+. Run `python3 scripts/validate.py`. This checks the planning repository, not application functionality.
